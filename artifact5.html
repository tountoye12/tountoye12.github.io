Dataset Exploration Project – Movie Data
Title

(Dataset Exploration)

by Mamadou Adama Diallo

Introduction

This project analyzes a dataset of 10,000 movies collected from The Movie Database (TMDb). The analysis focuses on identifying patterns and relationships between variables such as budget, revenue, vote count, and popularity. The goal is to translate raw data into meaningful insights using Python data analysis libraries.

Description

The dataset contains various movie attributes, including genres, cast, budget, and revenue. During cleaning, issues such as multiple values in the genres column (separated by |) and odd characters in the cast column were addressed. Adjusted budget and revenue values (budget_adj and revenue_adj) are included to account for inflation in 2010 dollars.

Objective

The main objective is to uncover relationships within the dataset and communicate findings effectively. Specifically, the project seeks to:

  • Identify correlations between revenue, budget, popularity, and vote count.
  • Explore which genres and characteristics are associated with higher revenue.
  • Provide actionable insights that can support further research or presentation.
Process
  • Collected and reviewed the TMDb dataset.
  • Cleaned and prepared data (handled missing values, split genres by |, ignored irrelevant columns).
  • Conducted exploratory data analysis (EDA) using statistical summaries and visualizations.
  • Identified correlations and key patterns.
  • Documented findings and insights for presentation.
Tools and Technologies Used
  • Python
  • NumPy
  • pandas
  • Matplotlib
  • Jupyter Notebook
  • TMDb Dataset (10,000 movies)
Value Proposition
  • Clarity: Simplifies complex movie dataset into clear findings.
  • Insight: Highlights strong correlations between budget, revenue, and popularity.
  • Practical Use: Can guide academic projects, data storytelling, or entertainment industry analysis.
  • Scalability: Process and methods can be adapted to other datasets for similar analyses.
Reflection

During this project, I learned the importance of data cleaning and preparation in shaping reliable insights. Handling missing values and reformatting columns such as genres improved the dataset’s usability. I also realized how simple visualizations and clear communication can turn complex data into accessible findings. This process strengthened my ability to apply Python tools effectively and reinforced the value of storytelling in data analysis.
